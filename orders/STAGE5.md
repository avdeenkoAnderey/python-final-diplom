## Ограничения

Настройка реальной доставки SMTP отменена по запросу пользователя.
В разработке письма выводятся в консоль, в тестах сохраняются в памяти.
Для накладных используется демонстрационный получатель `admin@example.com`.
Секреты из обоих файлов настроек удалены, локальный ключ и `.env.*` исключены из Git.
Старые секреты не обнаружены в текущих публикуемых текстовых файлах; история Git не переписывалась.
Проверена новая схема базы на установленном окружении, но не установка зависимостей в новое окружение из интернета.
Нагрузочная проверка и конкурентные запросы нескольких процессов не выполнялись.

Первый запуск теста с временным YAML встретил запрет песочницы на запись в системную папку Temp.
Повторный запуск с разрешённым доступом завершился успешно; изменения кода приложения для обхода ограничения не требовались.
